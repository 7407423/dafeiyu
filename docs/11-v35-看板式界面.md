# v35：看板式界面重构（花费 / 情绪 / 学习）

> 目标不是「好看」，是**打开就能看懂**：一眼四个数字，再往下才是细节。

## 0. 统一规范（以后改任何面板都按这个来）

```
① 卡片区   QGridLayout 排 4 张 StatCard：标题小字 + 数字大字 + 两行说明
② 图表区   QHBoxLayout 左右：趋势（柱/线）+ 占比（环）
③ 明细表   QTableWidget：斑马线、只读、行选中，最后一列比重
④ 说明栏   InfoBar：(i) 悬停看完整规则 + 右侧按钮（导出/操作）
```

四条硬规矩（写在 `ui/dashboard.py` 的模块注释里）：

1. **不用绝对定位**，全弹性布局，窗口拉伸不重叠；
2. 数字大、标签小（22~28pt vs 9~11pt）；
3. 长说明**永不**压在内容上 —— 进 `InfoBar` 的 tooltip，或表格下方单行；
4. 没有数据就说「暂无」，不画空轴、不显示 0% 的扇区。

## 1. 共享积木（`ui/dashboard.py`）

| 组件 | 作用 |
| --- | --- |
| `StatCard(title, color)` | 指标卡：`set(value, sub)`，数字大字 + 说明小字 |
| `TrendBars` | 近 N 天柱状图（QtCharts `QBarSeries`），悬停出当天金额 |
| `Donut` | 环形图（`QPieSeries`，`setHoleSize(0.55)`），右侧图例带百分比，悬停出金额 |
| `make_table(headers)` | 标准明细表：斑马线、只读、不换行、按需缩放 |
| `fill_table(table, rows, colors)` | 填表；`colors` 可按列或 (行,列) 上色 |
| `InfoBar(tip, text)` | 说明栏：`(i)` 悬停 tooltip + 右侧按钮位 |
| `money(v)` | 统一金额格式（小于 1 分显示三位小数） |

主题色 `ACCENT` 取蓝紫系：`#8b5cf6 / #6366f1 / #38bdf8 / #22d3ee / #f472b6 / #fbbf24…`，
图表背景 `#0f1620`、网格 `#1c2634`，和 `theme.qss` 同色。

## 2. 花费面板（`ui/panels/cost.py`）

**旧结构的问题**：一堆 QLabel 从上往下堆，底部三段长说明（QQ 账本/计价/语音）压在表格上，
窗口一缩就互相遮挡 —— 老大截图里那张「文字糊在一起」的就是它。

**新结构**：

| 区 | 内容 | 数据来源 |
| --- | --- | --- |
| 卡片① | 今日花费 + 私聊/群聊/后台拆分 + 轮次 | `cost.summary()["today"]` |
| 卡片② | 本月累计 + 累计总额 + 昨天 | `summary()["month"]["all"]["yesterday"]` |
| 卡片③ | 夜学最近一次 + 近 5 次均值 + 单次均价 | `summary()["learning"]` |
| 卡片④ | 本地缓存命中次数（表情字典复用 / 梗词自学） | `sticker.status()` + `memewiki.status()` |
| 图① | 近 7 天花费柱状图（悬停看金额） | `attribute()["by_day"]` |
| 图② | 按功能归因环形图（<1% 合并成「其他」） | `attribute()["by_tag"]` |
| 表 | 功能模块 / 调用次数 / 实际 / 均实际 / 均预估 / 偏差 / 占比 | `attribute()["by_tag"]` + 合计行 |
| 说明栏 | 共 N 次 / token / 实际 / 预估偏差 / 未分类条数 + `(i)` 完整计费口径 + 导出 CSV | — |

**修掉的重叠 Bug**：三段长说明现在只在 `(i)` 的 `QToolTip` 里；内容整体放进
`QScrollArea(widgetResizable=True)`，窗口再矮也是滚动，不会把卡片压扁。

## 3. 情绪面板（`ui/panels/emotion.py`）

卡片：当前情绪（主导+三维）｜内稳态（主导动机+三条）｜激素（皮质醇+四条+熔断）｜动态性格（外向+三维+偏移）。
左栏五维刻度 + 策略 + 记忆闸门；右栏内稳态三条 + 激素四条 + 基线；底部历史曲线 + 奖罚事件表（时间/触发/变化/RPE）。

以前 12 条刻度竖着排满一屏、还要往下滚才能看到事件；现在一屏就能答「她现在什么脸色、身体累不累、性格偏到哪了」。

## 4. 学习面板（`ui/panels/learning.py`）

卡片：待学队列（条数+最急的一条）｜好奇心主信号（最高的那个）｜知识缺口｜联网预算+疲劳。
两张表：意图队列（目标/来源/分数/可学性/状态）、知识缺口（领域/主题/缺什么）。
原来的长文本段落（信号、权重、疲劳挤在一行）拆成「卡片说结论 + 表格看明细」。

## 5. 顺带修的全局问题：顶部那条「栏目条」

旧 `DetailPage` 用一个 `QSplitter` + 固定 140px 的栏目列表，于是**每个面板打开第一眼都是
一块空卡片**（花费面板只有一个栏目，也占 140px）。现在：

- 只有 1 个栏目 → 整块收起（`setMaximumHeight(0)` + `setSizes([0, 640])`）；
- 多个栏目 → 高度按条数算（`12 + 26×n`，上限 150），不再固定 140。

## 8. 已知边界

1. QtCharts 是 PySide6 自带的（实测 6.12 可用），**不需要** `pip install PySide6-Charts`；换别的发行版才需要单独装。
2. 环形图把占比 <1% 的合并成「其他」，但明细表仍逐项列出（补丁要求「0 费用不画、但保留在表里」）。
3. 图表数据都来自 `cost.attribute()`，今天之外没有历史 `cost_event` 时柱状图会不足 7 根，这是数据问题不是显示问题。
4. 卡片里的「本地缓存命中」是**次数**不是钱：命中即 0 元，换算成金额只会是编的，所以只给次数。
