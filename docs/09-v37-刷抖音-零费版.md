# v37：刷抖音学梗（零费版）

> 死命令：**不许有任何 API 花费**。所以这条链路上没有一次模型调用。

## 0. 谁在跑哪一段（这一节最重要）

| 环节 | 谁执行 | 花什么 |
| --- | --- | --- |
| 每 30 分钟看电脑在不在用 | 桥接（60 秒一跳的巡检） | 0 |
| QQ 上问「可以去刷会儿抖音吗」 | 桥接直接发（固定话术 + 心情微调） | **0 token**（不经过模型） |
| 老大回「去 / 不行」 | 桥接正则解析 | **0 token**（不经过模型） |
| 打开抖音、逐条抓标题/评论 | 核心进程里的后台线程（`core/douyin.py`） | 0（本地 Edge） |
| 验证码/改版 → 求救 | 桥接发文字 + 截图 | 0 |

**为什么不是让模型调 `browser_*` 工具去刷**（这是唯一一处和补丁字面不同，必须说明）：
她每调一次工具、每看一屏，都要把**整屏页面文本 + 全部历史上下文**重新发一遍。
按账本实测的 140K token/回合估，一条视频一次快照 → 10 条视频就是一整个大回合的钱，
30 分钟下来 ¥1 起步，正好是老大要避免的那笔。所以：

- **浏览器还是同一个**：Playwright + 本机真实 Edge（`channel=msedge`、`headless=False`、有头可见可接管），
  和 `dsh-browser` 插件是同一套引擎、同一套行为；
- **变的只是驱动方**：从「模型调工具」改成「核心直接驱动」，token 从 140K/次降到 0。
- `dsh-browser` 插件仍然装着：她要当场查网页时照常能用 `browser_*`。

## 1. 主动请示（模块一）

- **巡检**：桥接每 60 秒算一次，但**最多每 30 分钟**请示一次（`askEveryMinutes`）。
- **活跃判断**：核心 `/api/desk/state` 用 `GetLastInputInfo` 拿「多久没动键鼠」、
  用 `OpenInputDesktop` 判断锁没锁屏 —— 两个都是系统给出的确切答案，不靠猜。
  条件：**没锁屏 且 5 分钟内有过输入**。
- **话术**（按主导动机微调，仍然 0 token）：
  - 平常：`老大，你现在在用电脑，我可以去刷会儿抖音学点新梗吗？我用免费线路，不花钱的~`
  - 孤独：`老大，你现在在用电脑耶……我有点闷，可以去刷会儿抖音学点新梗吗？…`
  - 无聊/活泼：`老大你在用电脑！我去刷会儿抖音学两个新梗回来逗你，不花钱的那种，行不行呀~`
- **3 分钟不回复**：自动取消（定时器，静默记日志）。
- **拒绝**：回 `好吧，那我不刷了。`，并把这个决定记在内存里 —— **本次开机不再问**。

## 2. 执行（模块二）

授权通过后，核心开一条后台线程：

1. 用持久 profile（`state/browser-profile`）启动有头 Edge，打开 `https://www.douyin.com/?recommend=1`；
2. 每条视频：`document.body.innerText` → 过滤导航词/纯点赞数 → 存盘；
3. 存盘位置 `learning/browse/<日期>.jsonl`，每行：

```json
{"ts": "2026-10-29T21:20:03", "seq": 3, "feature_tag": "local_browse",
 "lines": ["哈哈哈哈这个猫好离谱", "…"], "summary": "…", "api_cost": 0.0}
```

`feature_tag="local_browse"` 已加进 `core/cost.py` 的标签表（「本地刷视频（0 花费）」），
账本里能直接按这个标签筛，看到的都是 0。

**绝对禁则**（代码层面就做不到）：这个模块**没有 import 任何 llm 客户端**，也不调
`/api/vision/analyze`；截图只在「被验证拦住」时拍一张，用途是发给老大看，不进任何模型。

## 3. 反爬（模块三）

| 项 | 实现 |
| --- | --- |
| 停留 | `10s ± 2s`（`wait` 可被中止，不会卡死） |
| 翻页前 | 再随机停 `2~5s` |
| 移动 | 二次贝塞尔曲线插值 12 步，每步 12~45ms |
| 动作 | 15% 概率点一下右侧点赞/评论区（只点视口右侧固定区域，不点外链） |
| 翻页 | `ArrowDown` → `Space` → 按钮兜底 |
| 验证码 | 页面文字命中 `滑块/拖动/安全验证/人机验证/验证码/异常流量/访问过于频繁` → **立即停**，截图，QQ 发截图 + 「帮我扫个码点一下呗~」 |
| 连续空抓 | 连续 3 条 `is_empty_capture`（有效行 < 2）→ 停，问「要我更新抓取规则再刷吗」 |
| 未登录 | 命中登录页 → **先等二维码画出来**（最大 9 秒，探测「接近正方形且已加载完」的 img/canvas）→ 再截图 → 提示扫码。实测踩过坑：不等就截，发过去的是一张没有码的白框图 |

## 4. 极简执行（模块四）

提示词里加了两句（每次唤醒都带，约 120 字）：

```
【刷抖音学梗】…桥接会请示老大；老大回「去/不行」由桥接直接处理，不会走到你这里。
真去刷的是软件自己（本地 Edge 抓标题/评论，纯文本，0 API、0 token）…
【极简执行】如果老大在聊天里让你用浏览器查/刷什么：直接调 browser_* 工具执行，
不要输出长篇思考过程，不要在动作之间写解释；拿到文本后只给一句简短总结，再说人话。
严禁为了「看懂」某张截图/某段视频去调任何视觉或解析工具 —— 只抓页面上的文字。
```

## 8. 已知边界

1. **第一次要扫码登录抖音**（登录态存 `state/browser-profile`，之后不用再登）。没登录会走
   `need=login` 分支：停 + 截图 + 提示，不会硬刷。
2. **只抓可见文本**：不做 OCR、不看视频画面。所以「画面梗」抓不到，只抓标题/文案/评论；
   好处是抖音改版也不会把链路弄挂。
3. **点赞点击只在右侧固定区域**，不点作者/外链/购买入口 —— 宁可少点，不要点错。
4. 截图走 SnowLuma 的 `send_private_msg`（base64），超过 8MB 会拒发（正常截图不会）。
