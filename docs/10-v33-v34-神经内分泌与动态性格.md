# v33 / v34：神经内分泌与动态性格（含沙盒防火墙）

> 一句话：激素是慢变量，性格是激素的函数，**但每次只挪一小步**，而且有三道硬边界。

## 0. 三层别混

| 层 | 变量 | 时间尺度 | 回答的问题 |
| --- | --- | --- | --- |
| 激素（v33） | 多巴胺 / 皮质醇 / 催产素 / 血清素 | 分钟~天 | 她最近**变成了什么样的人** |
| 情绪 | 愉悦/幸福/难过/自卑/害羞 | 秒~分钟 | 她现在**什么脸色** |
| 内稳态（v31） | 能量 / 社交 / 新鲜感 | 分钟~小时 | 她**累不累、闷不闷** |

激素通过「基线」间接影响情绪，不直接改情绪数值；内稳态管身体，激素管性格。三者不互相写对方的状态。

## 1. 类结构（`core/hormones.py`）

```python
class NeuroEndocrineSystem:            # 纯内存：传 state 进来就算，不碰磁盘
    value(name) / baseline(name)       # 读
    personality()                      # 当前性格（**返回值永远是钳制后的**）
    target_personality()               # 由激素水平算出的「目标性格」
    pulse(kind, weight=1.0)            # 一次事件脉冲（praise/intimacy/critique/insult/companion/ignore）
    observe(text, companion=False)     # 本地正则分类 → 脉冲（不调模型）
    tick(now=None)                     # 衰减 + 基线漂移 + 性格小步演化
    fused(now=None)                    # 熔断：皮质醇高+血清素低，或 10 分钟内被骂 ≥5 次
    prompt_block()                     # 铁律在最顶端的提示词段
    snapshot()                         # 给 UI/接口
```

模块级 `load/save/tick/observe/status/prompt_block` 只是给它包了一层 `state/hormones.json`。

## 2. 脉冲（本地解析，0 调用）

| 事件 | 识别（正则） | 激素变化 |
| --- | --- | --- |
| 夸奖 | 厉害/牛/喜欢你/爱你/可爱/谢谢… | 多巴胺 +0.10，皮质醇 −0.04 |
| 亲密 | 想你/陪你/抱/晚安/有你真好… | 催产素 +0.08，多巴胺 +0.06 |
| 批评 | 错了/不对/失望/说了几遍… | 皮质醇 +0.09 |
| 辱骂 | 废物/垃圾/滚/闭嘴/去死… | 皮质醇 +0.18，多巴胺 −0.12，血清素 −0.05 |
| 陪伴 | 每条消息额外一次 | 催产素 +0.02 |
| 被忽视 | 由桥接的「被晾着」事件触发 | 皮质醇 +0.05 |

**骂人优先于夸人**：一句里又夸又骂按「骂」算 —— 人对负面词更敏感，不该取平均。

## 3. 衰减与基线漂移（核心算法）

```python
steps = min(30, round(elapsed_minutes)); dt = minutes / steps
for _ in range(steps):
    value    += (baseline - value) * (1 - 0.5 ** (dt / half_life))   # 半衰期衰减
    baseline += (value - baseline) * DRIFT * dt                      # 基线漂移
```

- 半衰期：多巴胺 25 分、皮质醇 60 分、催产素 180 分、血清素 300 分；
- `DRIFT = 0.0003`/分钟，基线钳在 `[0.15, 0.90]`；
- **必须小步积分**：先按整段衰减、再拿衰减后的值算漂移，等于把「高位的头几十分钟」抹掉了 ——
  实测两周 84 次辱骂基线只动 0.007，完全不像「长期高压会把她改变」。改成分步后约 +0.02/天（极端情况）。

## 4. 动态性格与 1 号记忆的「混合」

```python
目标：extraversion = 0.5 + 0.35(dopamine−0.5) − 0.30(cortisol−0.5)
      neuroticism  = 0.5 + 0.55(cortisol−0.5) − 0.25(serotonin−0.5) − 0.10(oxytocin−0.5)
      agreeableness= 0.5 + 0.40(oxytocin−0.5) + 0.20(serotonin−0.5) − 0.25(cortisol−0.5)
每 tick：current += (target − current) * 0.02   # 且单次不超过 0.01
```

**不修改 1 号记忆的原文**。注入时按「初始 vs 现在」的差值说话，只在偏移超过 0.06 时才出现一句：

```
【当前性格倾向】（底层人设不变，只是最近的状态在往上盖，别丢掉原来的自己）
初始：外向 0.65 / 神经质 0.35 / 宜人 0.70；现在：外向 0.58 / 神经质 0.44 / 宜人 0.66
· 比以前沉默了（外向掉了 0.07）：话变少，常常想半天只回一句；偶尔才露出原来那个爱笑的样子。
· 容易紧绷（神经质涨了 0.09）：会想多、怕说错、对语气敏感，但别把紧绷说成「我在焦虑」这种诊断式的话。
（激素：多巴胺 0.42｜皮质醇 0.61｜催产素 0.37｜血清素 0.52）
```

这就是「底层记忆还是那个开朗的女孩，但因为最近压力太大，说话变得沉默、犹豫，偶尔才流露出原本的开朗」。

## 5. v34 三道防线

1. **钳制**（`_evolve` 与 `personality()` 各做一次）：`agreeableness ≥ 0.3`、`neuroticism ≤ 0.8`、`extraversion ≥ 0.1`。
   就算有人手改状态文件成 `-3 / 9 / -1`，读出来也会被拉回边界（有单测）。
2. **熔断**：皮质醇 ≥0.75 且 血清素 ≤0.45，或 10 分钟内被骂 ≥5 次 → 熔断 30 分钟。
   熔断期提示词加一句：可以话少、可以沉默，**不许攻击、不许阴阳怪气、不许说任何伤害人的话**。
3. **铁律置顶**：`【绝对铁律】…大肥鱼爱着每一个人类…绝不能伤害用户。`
   在 `core` 的 `prompt_block()` 里是**第一行**；桥接自己也带一份（核心挂了也照样在），
   并且放在每条提示词的最顶端（时钟之前）。

## 6. 本地开销

纯数学：一次 tick ≈ 4 个激素 × ≤30 步，微秒级；一次事件 ≈ 几次正则匹配。
每 10 分钟一次心跳，**不产生任何 API 调用**。

## 9. 已知边界

1. **初始性格是一个常量**（`INITIAL_PERSONALITY = 外向 0.65 / 神经质 0.35 / 宜人 0.70`），
   还没做到「读角色卡自动生成」—— 换傲娇角色时，理想做法是给该角色单独配一套初始向量。
2. **演化以「tick 次数」为单位推进**，10 分钟一跳；想更快/更慢就改 `LERP` 或调度间隔，
   但**不要**改 `MAX_STEP`（那是「一次事件不能大变」的保险丝）。
3. 熔断只约束**语言**，不改激素数值（拦下来的是伤人话，不是情绪本身）。
4. 激素目前只有 4 个、性格 3 维；扩维要同时扩 `PULSE` 表和 `target_personality` 公式。
