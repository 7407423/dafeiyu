## 二、四处必须先拍板的冲突（做了会出事）

### ① 4.1「删除桌面对话」会切断核心的对话链路

现在桌面聊天是 `core/cognition/dialogue.handle_owner_message` 的唯一调用方：
拒绝权、v4 的回合节点、情绪/记忆联动、碎碎念策略全挂在这条链上。
QQ 那边走的是桥接自己的 agent，只回传 `{user_text, reply_text}` 给核心记节点，**不跑核心的 dialogue**。

直接删 UI = 核心对话逻辑变死代码（QQ 对话只有记录，没有拒绝权/情绪联动）。

**建议**：保留 `dialogue` 与 `/api/dialogue`，UI 上把对话框隐藏成"调试入口"（菜单里可开）；
或者把 QQ 的问答改成"桥接先把用户消息发给核心，核心回完再交给 agent"——工作量大、延迟高。
**默认按前者做**，需要你确认。

### ② 4.2「严格按草图」——我没有草图

这份需求里提到"草图1/草图2"，但会话里没有图。文字描述我能实现（左图 / 中三分 / 右功能栏 / 两态切换），
但"严格"两个字得有图才能保证。

### ③ 6 LICENSE：AGPL-3.0 + "非商业限制" 在法务上互斥

AGPL 明确禁止追加使用限制；加了"禁止商业使用"就不是开源许可，也不能叫 AGPL-3.0。
两条可行路线：
- **A（真开源）**：AGPL-3.0 全文 + 单独的 `NOTICE.md` 写"作者立场：不欢迎商业陪伴/付费代聊"（不具法律约束力）
- **B（真限制）**：PolyForm Noncommercial 1.0（允许非商业，禁止商业）+ 防滥用条款，但不能叫 AGPL

### ④ 1.1 学习窗口与关机时间打架

按新配置：学习 00:00–01:00，自我对话 = `window_end + 30` = **01:30**；
而现在关机是 **01:40**、还有 03:05 的"巩固"任务（跑在关机后，根本不会执行）。
只剩 10 分钟给自我对话（这是一次长写作，通常 10–20 分钟），基本跑不完。

**建议**：关机延到 **02:20**，巩固从 03:05 挪到 **01:10**（或在 `window_start` 前跑 23:50）。
