# 大肥鱼 · 安装提示词（复制给 AI 就行）

> 用法：把下面整段（从「你是……」到结尾）复制给任意能执行命令的 AI（DeepSeek Harness、Claude Code、Cursor、ChatGPT 的 Agent 模式都行），
> 把 `【下载地址】` 换成你的真实地址，再发出去。AI 会按步骤装好并启动。
>
> 如果 AI 只能聊天不能执行命令：让它把每一步的**命令**列给你，你复制到 PowerShell 里跑。

---

你是 Windows 装机助手。帮我在本机安装并运行「大肥鱼」桌面软件（一个会记事的 AI 伴侣），
一步一步来：每步先检查、再执行、执行完报告结果；失败就停下，把完整报错贴给我，不要自己猜着跳过。

## 硬性约束（必须遵守）

1. 如果本机已经装过大肥鱼（目录里有 `db`、`记忆系统`、`config`），**只允许覆盖程序代码**，
   绝对不要删除或覆盖 `config\`、`db\`、`state\`、`记忆系统\`、`logs\`、`learning\`。
2. 不要安装破解版、不要关杀毒、不要改系统代理。
3. 每一步都告诉我「在执行什么、为什么」；不要一次性静默跑完。
4. 装完必须实际启动一次并确认窗口出现，不能只解压就算完成。

## 目标

- 程序目录：`D:\dafeiyu`（如果 D 盘没有，用 `C:\dafeiyu`；不要放 `C:\Program Files`，不要放桌面）
- 装完能双击 `start.bat` 打开界面，并能和它正常对话
- 版本应为 **v0.9.2**

## 第一步：下载

- 下载地址：`【下载地址】`
  （示例：`https://github.com/<你的用户名>/<仓库>/releases/latest/download/大肥鱼-v0.9.2.zip`；
   如果你给我的是本地文件路径或网盘直链，也按同一个流程处理）
- 完成后核对：文件是 `大肥鱼-v0.9.2.zip`，大小约 **0.5 MB**（±20% 都算正常）。

## 第二步：核对系统

- Windows 10/11 64 位。
- 磁盘剩余 ≥ 2 GB。
- 运行 `py -3 --version`，需要 **Python 3.10 – 3.12**（3.13 / 3.14 暂时装不上 PySide6）。
  - 没有或版本太低：装 https://www.python.org/downloads/ ，安装时勾选 **Add python.exe to PATH**，
    装完关掉重开终端再验证。

## 第三步：解压

- 把 zip 解压到 `D:\dafeiyu`（如果已存在，先整个目录复制一份到 `D:\dafeiyu-备份` 再操作）。
- 确认 `D:\dafeiyu` 里有：`run.py`、`start.bat`、`core\`、`ui\`、`tools\`、`requirements.txt`。
- 不要出现 `大肥鱼\大肥鱼\run.py` 这种多套一层的结构；如果出现了，把里面那层的内容移到外层。

## 第四步：安装依赖并启动

打开 **cmd（命令提示符，不要用 PowerShell）**：

```cmd
cd /d D:\dafeiyu
start.bat
```

`start.bat` 会自动：建 `.venv` → `pip install -r requirements.txt` → 用 pythonw 启动。

- 第一次装依赖要 3~10 分钟，属正常。
- 如果 pip 卡住/超时，改成国内镜像重试：
  ```cmd
  .venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```

## 第五步：第一次运行

- 应该出现「大肥鱼」窗口，并弹出「初次见面」设定窗口（名字 / 性别 / 身高 / 性格）。
- 如果本机已经有 QQ 接入（`qq-bridge`），向导里会出现「检测到本机已有 QQ 接入」并默认勾选接管——
  保持勾选即可，它只会改配置，不会动记忆。
- 填完点「就这样开始」。

## 第六步：配置模型（必须，否则不回复）

打开 `D:\dafeiyu\config\llm.json`，把 `providers.http` 填成我的配置：

```json
"http": {
  "base_url": "https://api.deepseek.com/v1",
  "api_key": "【我的 API Key】",
  "api_key_env": "DEEPSEEK_API_KEY",
  "model": "deepseek-chat",
  "timeout_seconds": 120,
  "temperature": 0.8
}
```

并把 `tasks` 里的 `summary/compress/dialogue/chitchat/learning/self_dialogue/judge` 都设成 `"http"`。
保存后重启大肥鱼（关窗口再 `start.bat`）。

> 没有 API Key 也能先跑：保持 `default: "offline"`，她会用离线模板回话，界面和记忆功能都能验。

## 第七步：验收（必须逐条确认）

1. 任务管理器里有 `pythonw.exe` 进程。
2. 大肥鱼窗口能看到，标题是「大肥鱼」。
3. 左下角有花费/状态，右侧有功能栏，右下角有「修复 / 下载新版本」两个按钮。
4. 「关于」页显示的版本是 **0.9.2**。
5. 在桌面对话框（Ctrl+Shift+D）或 QQ 里说一句话，能收到回复。
6. 如果配了 QQ：QQ 接入页显示「桥接在跑」或「桥接未运行」但能看到已接管的目录。

## 第八步：创建快捷方式

在桌面新建快捷方式，目标填：

```
"D:\dafeiyu\.venv\Scripts\pythonw.exe" "D:\dafeiyu\run.py"
```

起始位置：`D:\dafeiyu`。图标选 `D:\dafeiyu\ui\assets\大肥鱼.ico`（如果存在）。

## 出问题按这个顺序排查

1. 双击没反应 → 在 cmd 里跑 `start.bat`，看完整报错。
2. `ModuleNotFoundError` → `.venv\Scripts\python.exe -m pip install -r requirements.txt`。
3. 中文乱码 → 先 `chcp 65001`，或在 `start.bat` 开头确认有 `chcp 65001`。
4. 杀毒软件拦截 → 把 `D:\dafeiyu` 加入信任目录（不要关杀毒）。
5. 窗口白屏/闪退 → 删掉 `.venv` 重新跑 `start.bat`；仍不行就把 `logs\` 里最新日志发我。
6. 提示端口被占用 → 关掉另一个大肥鱼进程，`state\singleton.lock` 删掉再启动。
7. 报 `0xC0000142` / PowerShell 起不来 → 一律改用 `cmd` 或双击 `start.bat`，不要用 PowerShell。
