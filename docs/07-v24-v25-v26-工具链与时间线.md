## 1. v24：三条工具链，按「不花钱 → 免费额度 → 付费」排队

### 1.1 先把真实环境核了一遍（和补丁描述有出入的地方）

| 补丁里说的 | 实际情况 | 怎么处理 |
| --- | --- | --- |
| `dsh plugin install ./dsh-memewiki` | CLI 只有 `dsh plugin --profile <n> <pnpm 参数>`，转发给 pnpm | 改用 pnpm 装，见 1.3 |
| 装着按 `--profile web` 装 | 桥接用的是 **`desktop`** profile（`~/.dsh/profiles/desktop`） | 装进 desktop |
| （没提） | `dsh --profile desktop` 直接被拒：「managed exclusively by the Electron application」 | 不走 CLI，直接改 profile 的 `package.json`（见 1.3） |
| `github:` 简写 | 这台机器**没装 git**，pnpm 的 `github:` 规格要 `git ls-remote`，直接失败 | 改成 `codeload.github.com` 的 tarball 地址（纯 HTTPS） |
| （没提） | 三个插件里 **抖音那个早就装了**（`dsh-douyin-browser-local@1.4.5`），只是**没进 bundles**，所以一直没挂载 | 补进 bundles |
| 装完要重启 DSH | 实测**不用**：改完 profile，工具当场出现在会话里（`browser_navigate`、`search_meme_wiki`、`douyin_*` 都是热挂上的） | 仍然建议重启一次求稳 |

两个插件仓库是真实存在的，不是编的：

- `Liujelly/dsh-memewiki` —— 本地 6668 条梗词库 + `search_meme_wiki` + 自动预查 + 设置页
- `duyefeng/dsh-browser` —— 驱动本机真实 Edge（`browser_navigate/_snapshot/_click/_type/_press/_evaluate/_screenshot/_close`）

### 1.2 梗百科为什么做了两份

**插件那份**（`dsh-memewiki`）在 DSH 里跑，提供 `search_meme_wiki` 工具和「常驻用法提示」，
但它是**模型主动调**才查 —— 遇到新词她不一定会调，而且调一次就是一步（一步 ≈ 158K token 上下文）。

**核心这份**（`core/memewiki.py` + `/api/meme/search`）是**桥接每条消息先替她查一次**：
命中就把词条贴进提示词（0 花费、0 步），查不到什么都不加（不占 token）。两份共用一个词库文件。

查询口径比插件多两层，专治「奶蛙」这种**只有长词条**的梗：

| 层级 | 例子 | 注入时怎么写 |
| --- | --- | --- |
| 1 同名 | `绝绝子` → `绝绝子` | 「词条「绝绝子」」 |
| 2 词条是句子的一部分 | `奶蛙是什么` → `奶蛙` | 同上 |
| 3 查询词是词条前缀 | `奶蛙` → `奶蛙之母`（取最短） | **「词库里没有同名条目，最接近的是「奶蛙之母」（按这个理解，别当成别的梗）」** |
| 4 标签命中 | `奶蛙` → `奶蛙被嫌弃` | 同上 |

> 第 3 层是实测逼出来的：词库里根本没有「奶蛙」这一条，插件会直接回 `found=false`；
> 但「奶蛙之母」「奶蛙被嫌弃」两条把奶蛙是什么讲得很清楚。给最接近的**并且如实说明**，
> 比一句「查不到」有用，也比假装是同一个梗安全。

### 1.4 工具的权限边界（`qq-tool-restrict.mjs`）

QQ 会话的守卫是**执行期白名单**：不在名单里的工具调用一律拒绝。所以新增了三样：

```js
const EXTRA_SAFE_EXACT = extraToolsEnabled() ? ['search_meme_wiki'] : []
const SAFE_PREFIXES = [ ...原有三个 MCP 前缀, ...(extraToolsEnabled() ? ['browser_'] : []) ]
```

总开关是 `state/allow-extra-tools.json`：写 `{"enabled": false}` 再重启 DSH 就收回。
默认开（老大点名要的）。⚠️ 这个文件**两份**（仓库 `plugins/qq-agent-presets/` 和
`~/.dsh/plugins/qq-agent-presets/`），改完要同步 —— 实测 PowerShell 的 `Copy-Item`
会因为文件被占用失败，用 Python 的 `os.replace` 可以覆盖。

### 1.5 抖音：**没有**启用那个会花钱的插件（老大明确不要 API 费用）

`dsh-douyin-browser-local` 本身是能用的，但它自带模型调用（spark 问候 / 自主评论 /
观察判定）——**每刷一条都可能打一次 API**。所以：

- 它已经**从 `bundles` 里移除**（保留依赖，不挂载）；`tools/v24_plugins.py` 里把它标成
  `mount: False`，以后跑 install 也不会再加回去；
- 它的策略文件本来也是 `enabled: false`（video-policy / chat-policy），实测没有产生过调用；
- 刷抖音改用**自己写的一条 0 API 链路**，见下面第 8 节。

「老大在用电脑吗 → 请示 → 同意才刷 → 30 分钟问一次」这套节奏，改由**界面按钮 + 日志**
承担（点「去刷会儿抖音」= 授权；日志里逐条记刷到第几条）。不额外做定时器：
定时器半夜自己开浏览器刷视频，比省下的那点事更吓人。

## 2. v25：时间线，让她知道「那是多久以前」

### 2.1 相对时间函数（`qq-bridge/src/time-tag.js`）

| 函数 | 输出 | 用途 |
| --- | --- | --- |
| `timeTag(ms)` | `刚刚` / `12分钟前` / `3小时前` / `5天前` | 纯标签 |
| `timeTagWithClock(ms)` | `[2小时前 (15:48)]`，跨天补日期 `[3天前 (10-26 15:48)]` | 贴正文前 |
| `dayLabel(ms)` | `今天` / `昨天` / `3天前` | 只有日期的 2 号记忆 |
| `absoluteClockLine()` | `【系统时间：2026年10月29日 星期四 17:48】` | 提示词最顶端 |
| `SPACETIME_RULES` | 4 条准则 | 紧跟时间行 |
| `staleComplaintNote({memText,lastIncomingAt})` | 纠偏提示 / 空串 | 状态覆盖 |

分档严格按验收标准：`<3 分钟` 刚刚、`<60 分钟` X分钟前、`<24 小时` X小时前、其余 X天前。
未来时间（时钟回拨）和非法输入返回**空串**，绝不出现「-3分钟前」。

### 2.2 贴在哪些地方

| 注入块 | 改法 |
| --- | --- |
| 系统时间 + 准则 | `withSlangContext()` 把原来的 `【当前时间】2026/10/29 21:05:12` 换成规格里的格式，准则紧随其后（每条投递都有，不依赖 preset 是否重启） |
| 日记 | `diaryAnnotatedBody()` 按 `## HH:MM` 分段，每段前贴 `[X小时前 (HH:MM)]`；没有时分的旧格式**不贴**，不编 |
| 瞬时记忆 | 每行 `[X小时前 (15:48)] 我〔模糊〕：…`（`〔模糊〕〔快忘〕` 是衰减刻度，保留） |
| 2 号长期记忆 | `- [难过·3天前（2026-10-26）] …`（只有日期粒度，就只给天级标签） |
| 跨线摘要 / 状态行 / 时间感块 | 原本就有 `X 前`，不动 |

### 2.3 状态覆盖（验收第 3 条）

`buildWakePromptV2` 里新增一块 `【纠偏】`：把日记 + 2 号 + 瞬时拼起来，
命中「没聊天/没人理/孤独/一下午没聊」这类抱怨词，**且** 数据表里有 30 分钟内的新来信时，
当场追加：

> （注意：上面那条「没聊天/没人理」是当时的感受；12分钟前你们其实已经又聊过了，别把当时的孤独当成现在的状态。）

实盘已经触发过（`bridge.log`）：`[prompt] 唤醒文本 14425 字｜…纠偏59…`。

## 3. v26：多图串行 + 报错不外泄

### 3.1 根因不是「并发解析」，是「她并发调工具」

桥接的媒体解析**本来就是串行的**（`resolveMediaList` 一个一个 `await`）。
真正错位的是：三张图一起进来时，老代码**只自动识别第一张**，剩下两张她得自己调
`qq_get_message_images` —— 于是她「一口气并发调三个看图工具」，DSH 流式拼接 tool 参数时就坏了：

```
DeepSeek Messages stream: tool input is invalid JSON
```

修法是**别让她并发**：`prefetchMediaDescription` 改成**逐张串行识别**，汇总成
`【图片内容·已自动识别】图1：… 图2：… 图3：…` 一次给她。每张先查本地表情字典（0 花费），
命中就不调视觉模型。上限 `socialV2.media.autoDescribeMax`（默认 3 张）。

### 3.2 报错拦截（`src/error-text.js`）

| 类别 | 例子 | 处理 |
| --- | --- | --- |
| 技术错误 | `invalid JSON`、`Traceback`、`ECONNRESET`、`502`、`fetch failed`、`请求超时` | 只进日志；先**降级重试一次**（纯文本 + 一次只调一个工具），不行才说人话 |
| 业务错误 | `消息未被接受：会话已过期` | 原样发（这是给人看的） |
| 空 | — | 说人话兜底 |

人话兜底是：「哎呀，刚才一下塞太多图，我的脑子打结了，老大再发一次试试？」
重试有节流：同一会话 2 分钟内只补一次，避免拿钱连续试错。

### 3.3 提示词也加了一条

`【省调用】`块后面加了`【多图】`：一次发多张时先输出一段连贯的文本总结，再决定要不要调工具，
别一边说话一边并发调多个工具。

## 7. 已知边界

1. **梗库是只读快照**（2026-10-26，6668 条）。新梗要更新就把新 `memes.db` 覆盖到
   `learning\memewiki\memes.db`，核心不改它。
2. **前缀兜底会说「最接近」**。为了不让她把「奶蛙之母」当成「奶蛙」的定义，
   注入文本里会明确写「词库里没有同名条目」。
3. **重试要钱**。技术错误重试一次 ≈ 一个普通回合的钱；同一会话 2 分钟内只补一次。
4. `state/allow-extra-tools.json` 是**总闸**：关掉它，`search_meme_wiki` 和 `browser_*`
   会从 QQ 会话的**执行白名单**里消失（工具还在 schema 里，但调用会被拒）。

## 8. 刷抖音学梗：0 API 花费的那条链路

### 8.1 钱到底省在哪

| 环节 | 谁来做 | 花什么 |
| --- | --- | --- |
| 看视频、读标题/评论 | 本机**真实 Edge**（`channel=msedge`，`headless=False`） | 0 |
| 理解「这些是什么梗」 | **网页版** `chat.deepseek.com`（同一浏览器、同一登录态） | 网页免费额度，0 API |
| 记下来 | `learning\memewiki\terms.json` + 本地 SQLite | 0 |
| 以后聊天时用到 | 桥接预查（`/api/meme/search`） | 只有正常聊天那点 token |

这个模块**不 import 任何 llm 客户端**（`core/webstudy.py` 里没有 `from .llm`），
所以「刷抖音会不会花钱」这个问题在代码层面就是不可能：没有可花钱的出口。

### 8.2 用法

界面：**记忆 → 刷抖音学梗** → 选分钟数 → 「去刷会儿抖音」。
第一次会弹出 Edge，要你**登录一次**抖音和网页版 DeepSeek（登录态存在
`state\browser-profile`，之后不用再登）。上面的「检查登录」只开窗口看状态，不刷。

命令行（等价）：

```powershell
python tools\webstudy.py probe                 # 只看登录状态
python tools\webstudy.py douyin --minutes 10    # 刷 10 分钟
python tools\webstudy.py terms                  # 看学到了什么
```

节奏按补丁要求：**每条约 10s（8~12s 随机）**，翻页前再停 **2~5s**，翻页用 `ArrowDown`/`Space`，
翻不动才试按钮选择器。

### 8.3 学到的词怎么用起来

`core/memewiki.py` 的查询顺序变成：**自己学的词 → 本地快照同名 → 快照包含 → 快照前缀**。
也就是她刚刷到的梗优先（比 2026-10-26 的快照新），而且照样是本地查表、0 花费。

### 8.4 这一步的已知边界

1. **第一次要手动登录**（抖音 + 网页版 DeepSeek 各一次）。没登录时模块抛 `NeedLogin`，
   界面会提示「在弹出的窗口里登一次」，不会静默失败。
2. **只读可见文本**：不做 OCR、不读视频画面。所以「画面里的梗」抓不到，只抓标题、文案、评论。
   好处是抖音改版不会把链路弄挂，也不用赌类名。
3. **网页版 DeepSeek 的 DOM 也可能改版**。`ask_web_deepseek` 用
   `textarea → [contenteditable] → [role=textbox]` 三级回退；真找不到会报「需要登录」而不是瞎猜。
4. 刷出来的词条质量取决于网页版模型的输出格式（`词|怎么用`）。解析不出来的行直接丢掉，不猜。
