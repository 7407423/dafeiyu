# 大肥鱼 · 一键安装提示词（复制给 AI）

> 用法：把下面整段复制给能执行命令的 AI（DeepSeek Harness、Claude Code、Cursor、ChatGPT Agent 都行），
> 它就会自己下载、解压、装依赖、启动。唯一的变量是最后的 `【API Key】`。

---

你是 Windows 安装助手。请帮我在本机下载、安装并运行「大肥鱼」——一个会记事、有情绪的桌面 AI 伴侣。
一步一步来：每步先检查、再执行、执行完报告结果；失败就停下，把完整报错发我，不要跳过、不要猜。

## 硬性约束

1. 如果本机已经装过大肥鱼（目录里有 `db`、`记忆系统`、`config`），只允许覆盖程序代码，
   绝对不要删除或覆盖 `config\`、`db\`、`state\`、`记忆系统\`、`logs\`、`learning\`。
2. 不要关杀毒、不要改系统代理、不要装破解版。
3. 每步都告诉我「在执行什么、为什么」。
4. 装完必须实际启动一次并确认窗口出现，不能只解压就算完成。

## 第一步：下载

直链（国内可直达，约 535 KB）：

```
https://gitee.com/adhwj68-67/dafeiyu/raw/master/dafeiyu-open-source-v0.9.3.zip
```

备用（GitHub 仓库，源码同版本）：

```
https://github.com/7407423/dafeiyu
```

下载到 `D:\dafeiyu-open-source-v0.9.3.zip`。
如果 Gitee 直链失败，再用 GitHub 的 `Code → Download ZIP`。

## 第二步：解压

解压到 `D:\dafeiyu`（不要放 `C:\Program Files`，不要放桌面）。
确认有：`run.py`、`start.bat`、`core\`、`ui\`、`tools\`、`requirements.txt`。
如果出现 `dafeiyu\dafeiyu\run.py` 多套一层，把里面那层内容移到外层。

## 第三步：检查 Python

运行 `py -3.12 --version`（没有就 `py -3 --version`），需要 **Python 3.10 – 3.12**。

- 没有 3.12：装 https://www.python.org/downloads/release/python-3129/ ，
  安装时勾选 **Add python.exe to PATH**，装完重开终端再验证。
- **不要用 3.13 / 3.14**：PySide6 还没有对应的安装包，`start.bat` 会明确提示。

## 第四步：安装依赖并启动

打开 **cmd（不要用 PowerShell）**：

```cmd
cd /d D:\dafeiyu
start.bat
```

`start.bat` 会自动：挑 3.12 → 建 `.venv` → `pip install -r requirements.txt` → 用 pythonw 启动。

- 第一次 3~10 分钟，正常。
- pip 卡住就换镜像：
  ```cmd
  .venv\Scripts\python.exe -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
  ```

## 第五步：首次运行

应该弹出「初次见面」窗口（名字 / 性别 / 身高 / 性格）。
如果本机已经有 QQ 接入（qq-bridge），会显示「检测到本机已有 QQ 接入」，**保持勾选**——它只改配置，不动记忆。
填完点「就这样开始」。

## 第六步：配置模型（必须，否则不回复）

打开 `D:\dafeiyu\config\llm.json`，把 `providers.http` 填成：

```json
"http": {
  "base_url": "https://api.deepseek.com/v1",
  "api_key": "【API Key】",
  "api_key_env": "DEEPSEEK_API_KEY",
  "model": "deepseek-chat",
  "timeout_seconds": 120,
  "temperature": 0.8
}
```

并把 `tasks` 里的 `summary / compress / dialogue / chitchat / learning / self_dialogue / judge`
都设成 `"http"`，保存后重启大肥鱼。

没有 Key 也能先跑：保持 `default` 为 `"offline"`，界面和记忆功能都能验。

## 第七步：验收（逐条确认）

1. 任务管理器里有 `pythonw.exe`。
2. 大肥鱼窗口出现，标题是「大肥鱼」。
3. 「关于」页版本显示 **0.9.3**。
4. 按 `Ctrl+Shift+D` 打开调试对话，说一句话有回复。
5. 如果配了 QQ：QQ 接入页能看到「桥接在跑」或已接管的目录。

## 第八步：桌面快捷方式

桌面新建快捷方式，目标填：

```
"D:\dafeiyu\.venv\Scripts\pythonw.exe" "D:\dafeiyu\run.py"
```

起始位置：`D:\dafeiyu`。图标选 `D:\dafeiyu\ui\assets\大肥鱼.ico`（如果存在）。

## 出问题按这个顺序排查

1. 双击没反应 → 在 cmd 里跑 `start.bat`，看完整报错。
2. `ModuleNotFoundError` → `.venv\Scripts\python.exe -m pip install -r requirements.txt`。
3. 中文乱码 → 先 `chcp 65001`。
4. 杀毒拦截 → 把 `D:\dafeiyu` 加信任目录（不要关杀毒）。
5. 窗口白屏/闪退 → 删掉 `.venv` 重跑 `start.bat`；仍不行把 `logs\` 最新日志发我。
6. 端口占用 → 关掉另一个大肥鱼，删 `state\singleton.lock` 再启动。
7. 报 `0xC0000142` / PowerShell 起不来 → 一律用 `cmd` 或双击 `start.bat`。
