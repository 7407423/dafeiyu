# v36：身份注水 + v2 图片自动识别（修复「认错人」和「看图说不行」）

## 0. 两个现象、两个根因

| 现象 | 根因 |
| --- | --- |
| 把用户A发的吃面图算到老大头上，还把 QQ 号念错一位（3412→3421） | 模型看到的消息**只有 sender 昵称、没有 QQ 号**；跨线摘要里更只有「群聊/私聊」和名字。多条私聊线并排时，她只能猜 |
| 九点发三张表情包，她说「不行」 | **v2（仿真）模式从来没调过 `prefetchMediaDescription`** —— 自动识图只挂在一代模式的分支里。于是 v2 既没有图片描述、也不附图片字节，她手上只有 `[图片]`/`[表情]` 两个占位符 |

## 1. 身份注水（补丁核心）

**唯一入口：`compactModelMessage`**（`src/qq-model-view.js`）。v2 快照、批量上下文、追问提示词全部经过它，改一处全生效。

```js
export function senderTag(message) {
  const sender = String(message?.sender ?? '').trim();
  const qq = String(message?.userId ?? message?.user_id ?? '').trim();
  if (!sender && !qq) return '未知用户';        // 异常时不沿用上一个人
  return qq ? `${sender || '未知用户'}(QQ:${qq})` : sender;
}

// 别人的消息：
result.from = tag;                              // 结构化字段，方便工具也读
result.text = `[来自 ${tag} 的消息] ${result.text}`;
```

效果（实际进 prompt 的样子）：

```
[来自 用户A(QQ:100000001) 的消息] [图片]
[来自 老大(QQ:100000000) 的消息] 你看看我
```

- 自己发的不打标签（`isSelf`）；
- 已经有前缀的不重复加；
- 解析不出发送者时写 `[来自 未知用户 的消息]`，**绝不套用上一个说话人**。

## 3. 修 v2 的图：三条一起上

1. **v2 也触发后台识图**：`handleIncoming` 的 `currentMode === 'reserved2'` 分支里补上
   `prefetchMediaDescription(...)`（以前只有一代模式有）。
2. **描述进快照**：`buildWakeSnapshotV2` 的 `tryAdd` 里按 `msg.messageId` 取 `mediaDescByRef`，
   拼到**这条消息**的文本后面（带发送者）。
3. **投递前等一等**：`deliverPromptNow` 里 `await Promise.race([全部在途识图, 25 秒])`，
   让「刚发来的图」这一轮就能被描述到；超时也照常投递（下一轮用字典，0 花费）。

## 4. 身份铁律（提示词，紧跟身份块）

```
【身份识别铁律】你正在同时和多个不同的人聊天（私聊或群聊）。每个人发来的消息前面都带
[来自 昵称(QQ:号)] 标签，图片描述里也写明是谁发的。
1. 必须核对每条消息、每张图的发送者标签；
2. 绝不把 A 发的内容算到 B 头上，也绝不把别人私聊里的图/话复述给另一个人；
3. 私聊里你的回复对象只能是这个会话的当事人；不确定就把标签里的名字原样念一遍，别猜、别改号。
```

第 3 条后半句是专门针对「把 100000001 念成 100000001」加的：**不许自己改写数字**。

## 5. 隔离边界（本来就有的，这里说清楚）

- 每个 QQ 会话在 DSH 里是**独立 session**（`private:<QQ号>` / `group:<群号>`），上下文物理隔离；
- 唯一的「跨线可见」是 `crossTalkDigest`（老大私聊能看到群聊摘要，群能看到老大私聊摘要）——
  它现在每条都带 `昵称(QQ:号)`，且只给「摘要级」内容，不给图片；
- 图片描述存在 `mediaDescByRef`（按 messageId 键）与核心字典（按 sha256 键），**都不按人分组**，
  所以归属只能靠消息标签 —— 这就是为什么标签必须贴在消息上，不能靠「她记得」。

## 8. 已知边界

1. **第一次见到某张图仍然要花一次视觉钱**（否则谁也说不清图里是什么）。识别结果进 `sticker_cache`，
   同一张图第二次开始 0 元；这条链路在 v29 之后就是「命中绝不调视觉」。
   想让新图也完全不花钱：`qq-bridge/config.json → socialV2.media.autoDescribe=false`（代价是只看到 `[表情:备注]`）。
2. QQ 自带表情（face）不走向量识图，靠昵称/备注描述。
3. `crossTalkDigest` 仍会把「另一条线的摘要」给到老大私聊 —— 这是既定功能（两条线互通），
   但它只给**文字摘要**、不带图片，也不会告诉群里「老大私聊说了什么」。
